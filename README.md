# Reliability-Oriented Brain Tumour Segmentation — Research Project

> **Research in progress. Experimental results have not yet been established.**

This repository currently contains only the **research-design phase**: literature review, gap analysis, candidate research directions, dataset strategy and experimental design. It contains no model code, no data, no trained models and no results.

## Current status

| Phase | Status |
|---|---|
